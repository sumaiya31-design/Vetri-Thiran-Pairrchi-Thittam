Project Title

EduGenie – Google Gemini Powered Learning Assistant

Project Overview

EduGenie is a lightweight AI-powered educational assistant designed to help students learn more effectively using Generative AI. It allows users to ask questions, understand complex concepts through simplified explanations, generate quizzes, summarize educational content, and receive personalized learning recommendations. The system uses FastAPI for the backend, an HTML/CSS frontend, and Google Gemini for AI-powered learning functions.

8 Project Phases
1. Brainstorming & Ideation Phase

The project idea was developed by identifying the need for a simple AI-based learning assistant. Different educational applications were considered, and EduGenie was proposed to provide multiple learning activities in one platform, including Q&A, explanations, quizzes, summaries, and learning paths.

2. Requirement Analysis Phase

The required features, software and technologies were identified. The project requires Python, FastAPI, HTML, CSS, Google Gemini API, Uvicorn and Jinja2. The main functional requirements include question answering, concept explanation, quiz generation, summarization and personalized learning recommendations.

3. Project Design Phase

The system was designed using a modular architecture. The main components include main.py, explanation_module.py, qna.py, quiz_module.py, summary_module.py, learning_path.py, index.html and style.css. Separate modules handle different educational functions.

4. Project Planning Phase

The development work was organized into milestones covering AI model selection, core functionality development, frontend development and deployment. AI models were selected according to the required tasks, and the project structure and development activities were planned accordingly.

5. Project Development Phase

The core modules and FastAPI backend were implemented. REST API endpoints were created for Q&A, explanation, quiz generation, summarization and learning recommendations. The frontend was also developed with a task selection menu, input area and result display.

6. Project Testing Phase

The application was tested by running it locally and checking each major function. Testing included asking questions, getting explanations, generating quizzes, summarizing content and obtaining personalized learning plans. The frontend and backend integration were also checked.

7. Project Documentation Phase

The project documentation records the project description, prerequisites, architecture, modules, API endpoints, frontend development, deployment, testing, conclusion and future enhancements. This documentation provides a complete reference for understanding and presenting the project.

8. Project Demonstration Phase

The final application is demonstrated through its web interface. The demonstration shows the major features: asking questions, explaining concepts, summarizing text, generating quizzes and providing learning recommendations. The FastAPI API documentation can also be shown during the demonstration.

Short Overall Conclusion

EduGenie provides a single AI-powered platform for interactive and personalized learning. By combining Generative AI with a lightweight web interface, it supports students with explanations, Q&A, quizzes, summaries and structured learning paths.
